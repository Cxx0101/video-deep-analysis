# 视频深度分析工具（网页版）

这是一个本地运行的网页工具：上传短视频或输入公开视频链接，即可生成深度图、人体姿态骨架和面部 478 点网格叠加后的 MP4。

支持 Windows 10/11 和 macOS（Apple Silicon 需 macOS 11+，Intel 需 macOS 10.15+），使用 Python 3.11。服务只监听本机地址 `127.0.0.1`，不会把上传的视频传到远程服务。

## 功能

1. 灰度深度图
2. 人体姿态骨架叠加
3. 深度图 + 人体姿态骨架
4. 面部 478 点网格
5. 深度图 + 人体姿态 + 面部网格全部叠加

输出会自动校正视频旋转方向、保留原视频音频（包括背景音乐），并生成浏览器兼容的 H.264/AAC MP4。

## 简单启动

请先安装 Python 3.11。首次启动会自动创建独立虚拟环境并安装依赖，之后直接启动网页服务。

### Windows（PowerShell）

直接双击 `启动网页版.bat`。首次安装依赖可能需要几分钟；启动后请保持弹出的命令窗口开启，关闭它会停止网页服务。

如果系统没有关联批处理文件，可在本目录执行：

```powershell
py -3.11 start.py
```

### macOS（终端）

```bash
cd /你的项目路径/视频深度分析工具
python3.11 start.py
```

启动后会自动打开浏览器；也可手动访问 <http://127.0.0.1:8000>。按 `Ctrl+C` 停止服务。

首次使用深度图功能时，程序会自动下载 MiDaS Small ONNX 模型到本项目的 `models/` 目录。深度图固定使用 OpenCV DNN 的 CPU 推理；Windows 和 macOS 的运行方式一致，无需 CUDA。

## 使用方法

1. 上传不超过 500 MB 的 MP4、MOV、AVI、MKV、WebM、M4V 或 FLV 视频，或粘贴有权下载的公开视频链接。
2. 选择分析模式并点击“开始分析”。
3. 处理完成后在网页中预览并下载 MP4。

视频链接下载使用 yt-dlp，仅应处理你有权下载和使用的公开内容；播放列表不会被下载。

## Git 说明

模型、缓存、虚拟环境、上传视频和处理结果均由 `.gitignore` 排除。克隆项目后按上方命令安装依赖；模型会在首次需要时下载。
