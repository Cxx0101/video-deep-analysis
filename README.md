# 视频工具集（网页版）

本项目是运行在本机的网页视频处理工具。导入一次视频后，可以预览素材，并在不同工具之间重复使用该视频来源。

服务只监听 `127.0.0.1`，本地上传的视频不会被本项目上传到远程服务器。通过链接下载时由 `yt-dlp` 访问对应视频站点，请仅处理你有权下载和使用的内容。

## 当前功能

### 视频智能分析

支持以下五种分析模式：

1. 灰度深度图
2. 人体姿态骨架叠加
3. 深度图 + 人体姿态骨架
4. 面部 478 点网格
5. 深度图 + 人体姿态 + 面部网格全部叠加

分析结果会校正视频旋转方向、保留原始音频（包括背景音乐），并输出浏览器可播放的 H.264/AAC MP4。

### 音视频分离

左侧工作台的“音视频分离”是独立功能入口。选择已导入的视频后，可导出：

- 无声 H.264 MP4 视频
- 独立 MP3 音频

不会修改原始视频。若源视频没有音轨，音频导出会给出明确提示。

### 人像与背景分离

左侧工作台的“人像与背景分离”提供独立处理区域，可识别视频中的人物并保留原始音频，输出浏览器可播放的 MP4。可选择：

- 背景虚化
- 白色背景
- 黑色背景
- 人像蒙版（白色人物、黑色背景）
- 透明背景：导出带 Alpha 通道的 VP9 WebM，可用于后续合成

除透明背景外均输出 MP4；透明背景必须使用 WebM 才能保存透明通道。复杂遮挡、多人或极快运动的素材，人物边缘可能出现轻微误差。

### 帧提取与剪辑

左侧工作台的“帧提取与剪辑”包含两项独立功能：

- 按帧提取：设置“每隔多少帧提取”；设为 `1` 即导出全部帧。图片会以 JPEG 格式打包为 ZIP，并提供首帧预览。单次最多导出 5000 帧。
- 剪辑片段：提供简洁的素材缩略图时间轨，自动从视频生成画面缩略图；拖动左右手柄设定起点和终点，拖动白色选区可整体移动片段，点击轨道可快速调整。下方秒数输入可精确微调。输出为精确剪辑的 H.264/AAC MP4，并保留原始音频。

### 视频来源

- 上传本地 MP4、MOV、AVI、MKV、WebM、M4V 或 FLV，最大 500 MB。
- 粘贴公开视频链接，或包含 `https://v.douyin.com/` 的完整抖音分享文案后下载并预览。
- 通过 Get cookies.txt LOCAL 导出的 Netscape 格式 `cookies.txt` 可保存到本机，后续链接下载会自动使用。Cookie 文件保存在 `data/cookies.txt`，不会提交到 Git。

## 运行环境

- Windows 10 / 11 64 位或 macOS
- Python 3.11
- 不需要 Docker、WSL、Conda 或 CUDA
- 全部推理使用 CPU；首次使用深度分析时会下载 MiDaS Small ONNX 模型到 `models/`

## 启动

首次启动会创建 `.venv` 并安装依赖；之后会直接启动服务。

### Windows

双击 [启动网页版.bat](启动网页版.bat)，并保持弹出的命令窗口开启。

若双击被系统拦截，请在项目目录执行：

```powershell
py -3.11 start.py
```

### macOS

```bash
cd /你的项目路径/深度视频
python3.11 start.py
```

启动后浏览器会自动打开，默认地址为 <http://127.0.0.1:8000>。如果该端口已被旧服务占用，工具会自动改用 8001–8010 中的可用端口并打开正确页面。按 `Ctrl+C` 停止服务。

## 使用流程

1. 上传本地视频，或下载网络视频并确认预览。
2. 在左侧工作台选择“视频智能分析”、“音视频分离”、“人像与背景分离”或“帧提取与剪辑”。
3. 选择所需选项并开始处理。
4. 在结果区预览并下载导出文件。

## 项目文件与 Git

- `app.py`：FastAPI 接口、视频处理、下载和音视频分离逻辑。
- `static/index.html`：网页工具集界面。
- `start.py` / `启动网页版.bat`：跨平台及 Windows 简化启动入口。
- `smoke_test.py`：五种智能分析模式的本地回归测试。
- `PROJECT_CONTEXT.md`：维护和后续开发时应先阅读的项目上下文。

模型、虚拟环境、运行日志、视频来源、Cookie 和处理结果都在 `.gitignore` 中排除。新增或完成用户可见功能时，会同步更新本 README 与 `PROJECT_CONTEXT.md`。
